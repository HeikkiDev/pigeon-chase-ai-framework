Raspberry Pi 3B verification — REQ-DET-003

Goal: on a Pi 3B (1 GB, 64-bit Raspberry Pi OS) the detection model must run at ≥ 5 FPS, inference only, on 640×480 frames. No camera needed: the benchmark replays a recorded frame from disk. Branch: real-detector (pushed, PR not opened yet).

1. Prepare the Pi

Flash 64-bit Raspberry Pi OS Lite. Confirm uname -m prints aarch64.

sudo apt update
sudo apt install git cmake ninja-build g++ libomp-dev

2. Build ncnn from source

git clone --depth 1 https://github.com/Tencent/ncnn.git && cd ncnn
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DNCNN_VULKAN=OFF \
  -DNCNN_BUILD_TOOLS=OFF -DNCNN_BUILD_EXAMPLES=OFF -DNCNN_BUILD_BENCHMARK=OFF \
  -DCMAKE_INSTALL_PREFIX=/usr/local
ninja -C build -j2 && sudo ninja -C build install
cd ..

-j2 avoids running out of the 1 GB of RAM.

3. Build the benchmark

The CMake presets are macOS-only, so call CMake directly.

git clone -b real-detector https://github.com/HeikkiDev/pigeon-chase-ai-framework.git
cd pigeon-chase-ai-framework
cmake -S . -B build/pi -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja -C build/pi -j2 pigeon_detector_benchmark

4. Run it

Same settings as the upstream 62 ms figure (4 threads, bf16):

M=raspberry/models/yolo-fastest-1.1
build/pi/tools/pigeon_detector_benchmark --param $M/yolo-fastest-1.1.param \
  --weights $M/yolo-fastest-1.1.bin --threads 4 --bf16 --repeats 200 \
  tests/raspberry/fixtures/pigeon_640x480.ppm

Then run it once more without --bf16 for comparison.

5. Read the result

  • Pass: the sustained line is ≥ 5 FPS (upstream suggests ~16 FPS).
  • Also note frames FOUND, median inference and peak RSS.
  • Fail: the documented fallback is TFLite, which needs a new ADR.

For reference, the Mac output looked like this (meaningless for the Pi):

frames            50 (1 x 50, 640x480 RGB888)
threads           4
bf16 storage      off
threshold         0.55
frames FOUND      50
median inference  1.84233 ms
slowest inference 2.84225 ms
sustained         502.316 FPS
peak RSS          32 MiB

6. Optional: run the test suite on the Pi (ARM64 portability)

cmake -S . -B build/pi-test -G Ninja -DCMAKE_BUILD_TYPE=Debug -DPIGEON_BUILD_TESTS=ON
ninja -C build/pi-test -j2 && ctest --test-dir build/pi-test

7. Send back to Copilot

Paste the full benchmark output plus:

cat /etc/os-release
uname -a
vcgencmd measure_temp

Also say how the Pi is powered and cooled (a Pi 3B slows itself down when hot). Copilot then records the result in docs/architecture/, updates REQ-DET-003's status, and opens the PR.

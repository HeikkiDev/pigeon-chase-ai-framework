1. Pictures provided by the camera must be analyzed with an Object Detection model and produce one of the following states for the object recognition: NONE or FOUND.
2. If the Object Detection model returns 3 consecutive FOUND, then the pigeon will be considered by the system as TARGET_LOCKED. Then the system will sent the movement instructions to Arduino. After that, must verifiy the pigeon is still there with one more picture with FOUND. Then send Arduino the instruction to trigger the water gun.
3. The target system have 3 states: SEARCHING, TARGET_LOCKED and TARGET_LOST. TARGET_LOST will be only produced after a TARGET_LOCKED when the system checks again a camera frame with the object detection model before it sends the shoot instruction to Arduino for the water gun. After TARGET_LOST, the state is again SEARCHING.
